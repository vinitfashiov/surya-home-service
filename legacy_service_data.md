## Notes for Migration

1. **Old system:** MySQL (MariaDB) with PHP backend (Vivah Bazaar)
2. **New system:** Supabase (PostgreSQL) with React/TypeScript frontend (Vibe Service)
3. **Provider ID in old system:** Services were tied to providers via `subscribed_services` table
4. **Tax:** All services had 5% tax rate
5. **Zone-based pricing:** Variations were linked to zones (Bihar was the only active zone)
6. **Deleted services:** 5 services were soft-deleted (Car Booking duplicates, Camera bundle, Test Service)
7. **Images:** Old system stored image filenames like `2025-09-11-68c28d333e38b.png` - these would need to be re-uploaded to Supabase storage
8. **Service descriptions:** Original descriptions contained detailed Hindi+English HTML content with features, pricing breakdowns, and "Why Choose Us" sections
